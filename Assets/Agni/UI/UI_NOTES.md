# Agni Royale — Loading + Lobby (step 2a, Nov 1 2026)

Flow: **Intro** (mascot, ~5 s, tap = skip) → **Loading** (season key art, progress bar, rotating Hinglish tips, TAP TO START → first-launch name popup) → **Lobby** → START → **AgniMap** (free-fly map test for now).

All screens are built from code at runtime (uGUI, legacy Text with our OFL fonts); each scene holds one GameObject:
- `Loading.unity` → `AgniLoadingScreen` (nextScene "Lobby"). Name: 4–12 chars, letters/digits/space/_ . -, PlayerPrefs `agni.playerName`.
- `Lobby.unity` → `AgniLobby` (matchScene "AgniMap"). Centre: Kenney CC0 mini character (Resources/AgniChar, idle clip sampled in code) on a teal/gold platform + Agni mascot pet (sprite, hop + blink). Top-left player card (name, LV, XP, Kaansa III badge), top-right Sikke + Agni Ratna (0) + settings gear, left column Store/Bag/Character/Pet/Events → "Jaldi aa raha hai" panel, bottom-left squad slots (+ → coming soon), bottom-right mode selector (Classic · Bharat Map; Squad 4v4 locked) + START, bottom-centre season tag.
- Lobby music hook: `AgniLobby.lobbyMusic` (AudioClip) or `Resources/AgniAudio/lobby_theme` — plays looped at the Music volume. None shipped yet (CC0 dhol/shehnai later).
- Settings (`AgniSettingsPanel`, `AgniSettings` in AgniCore.cs), saved in PlayerPrefs and applied instantly: Graphics Smooth/Standard/Ultra (quality level Mobile/Mobile/PC; on device also URP render scale 0.75/1/1, MSAA 1/1/4, shadow distance 0/40/90), FPS 30/60 (`Application.targetFrameRate`), Sensitivity 0.2–2.5x (`agni.sens`, read by AgniFlyCam), Sound effects + Music volume, Language English/Hinglish (Hindi greyed = coming). Reset + Done.
- Canvas: Screen Space – Camera, reference 2400×1080 matched on height (16:9 is just narrower), `SafeArea` component keeps HUD inside Screen.safeArea.

Art (all our own, generated by code — `Tools/ui_gen/*.py`, skia): `Resources/AgniUI/` — poster_s1.jpg (loading key art; uses our design/agni_map_v2), lobby_bg.jpg, 9-slice kit (rr_/btn_/btno_/ol_ + shadow), icons (ic_*), cur_coin / cur_gem, rank_kaansa, mascot_* (rendered from design/intro_src/render_intro.py). Import settings come from `AgniUITexturePost` (Editor/AgniUISetup.cs). No Garena / Free Fire names, art, icons or UI copies.

## Commands
- (Re)create scenes + build order Intro → Loading → Lobby → AgniMap:
  `timeout -k 15 600 $UNITY -batchmode -quit -nographics -projectPath $PROJ -buildTarget Android -executeMethod Agni.UI.EditorTools.AgniUISetup.CreateBatch -logFile /tmp/agni/ui_setup.log`
- Proof screenshots (play mode in batchmode, needs Xvfb; writes 01..08 PNGs, editor-only driver AgniProofDriver.cs):
  `Xvfb :93 -screen 0 1920x1080x24 -nolisten tcp &` then
  `DISPLAY=:93 timeout -k 15 400 $UNITY -batchmode -force-glcore -projectPath $PROJ -buildTarget Android -executeMethod Agni.UI.EditorTools.AgniUISetup.ProofBatch -agniProof <outDir> -logFile /tmp/agni/ui_proof.log`


## Lobby v2 — animated MAHAL + UI overhaul (2026-11-01, task 28c731d3)
- Background is now 3D, built in code by `AgniMahal.cs` (no flat lobby_bg): marble courtyard + red carpet + water channel (fountains), potted topiary,
  two-storey arcaded palace wings (pointed arches, jharokhas, chhajjas, chhatris, banners, lit halls; right wing a storey taller) running ~400 m,
  darwaza gates at z 80/165/260/370 (the "endless" read), domed pavilions + towers behind the wings, a far palace at z 520, 3 hill layers, gradient sky + sun.
  Our own palace design: no temples / religious symbols (domes carry plain gold pinnacles).
  Geometry is merged per material per depth zone (z<30, <90, <200, rest) => ~38–41 meshes total. The whole Mahal root is turned 12° so the vista opens beside the hero.
- Animation: camera drift, flags (CPU cloth wave), pigeons (flapping), clouds, diya flicker, fountains + petals (particles), light shafts (VERY HIGH), 120 s golden-hour↔sunset cycle.
- Quality = Settings ▸ Graphics LOW / NORMAL / HIGH / VERY HIGH (`GfxPreset` Smooth/Standard/Ultra/VeryHigh). LOW: shorter wings, 2 gates, no fountains/petals, no shadows from the palace, no bloom;
  HIGH: bloom (threshold 1.3, HDR emissive only), palace shadows near the camera, petals; VERY HIGH: + light shafts, more birds.
  Measured in the editor at 1920x1080: HIGH ≈ 504 batches / 79 SetPass / 385k tris; LOW ≈ 112 batches / 32 SetPass / 164k tris. Not measured on a phone yet.
- HUD renders through its own URP overlay camera (`UICamera`, in the base camera's stack) so bloom never touches the UI.
- Character: anime Meera (characters_anime, copied to Agni/Characters/Resources/AgniChars) with the AgniRoyale/AnimeToonOutline shader, LOD by graphics level, procedural idle `AgniIdle` (breathing, weight shift, arms out of A-pose). Kenney CC0 character = fallback.
- Audio: Assets/Resources/AgniAudio/lobby_theme.ogg (streams) + sfx_*.ogg (button tap on every K.Btn, popup open on PopIn, confirm on START), volume from Settings.
- Proof: `-executeMethod Agni.UI.EditorTools.AgniUISetup.LobbyProofBatch -agniProof <dir> -agniMode lobby [-agniGfx 0..3] [-agniPanels 1] [-agniVideo <frames>]`
  (shots at 2400x1080, 1920x1080, 1600x720 and a simulated 4.5% left notch; frames are 1280x720 @ 24 fps with a fixed timestep; the HUD overlay is composited on the CPU because Camera.Render() skips URP overlay stacks in batchmode).
